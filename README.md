## 💡 About

**Night Owl** is a stylized login page UI built around a deep dark green and gold color palette. The design focuses on atmosphere — a moody, minimal aesthetic with clean form interactions and a two-column split layout.

Built as my fifth front-end project, focusing on form UI design, custom input styling, and small but polished JavaScript interactions.

---

## ✨ Features

- **Password Toggle** — Show/hide password with eye icon, icon swaps on click
- **Custom Radio Checkbox** — "Remember me" styled as a circular dot indicator
- **Split Layout** — Two-column design with form on the left and visual on the right
- **Social Icons Bar** — Vertical stack of gold circular icon buttons
- **Sticky Gold Inputs** — Transparent inputs with gold border and pill shape
- **Hover & Transition Effects** — Smooth color and scale transitions throughout
- **Responsive Design** — Stacks to single column on mobile

## 🧠 What I Learned

- Styling a **custom checkbox** from scratch using pure CSS — hiding the native input and building a circular dot indicator with `:checked` pseudo-class
- Implementing a **password visibility toggle** by switching the `type` attribute between `password` and `text`, and swapping Font Awesome icon classes simultaneously
- Building a **two-column split layout** with `flexbox` where each side has distinct content and alignment
- Using **CSS custom properties** to manage a tight, consistent color palette across the entire UI (only 5 core variables)
- Styling **pill-shaped inputs** with `border-radius: 25px` and transparent backgrounds while keeping them readable and accessible
- Creating atmosphere through **layered radial gradients** on the body background
